Evaluation

Does it beat persistence?

Bars show each model's RMSE relative to persistence in the same row group. Skill is the MSE skill score against persistence: 0 means no better than "next hour equals this hour", 1 means perfect. Results are on the cleaned OMNI science product, so real-time performance will be lower.

Data: NASA SPDF OMNI2, NOAA SWPC real-time solar wind, WDC Kyoto Dst. Models and code on GitHub. A research demo, not an operational alert service.
